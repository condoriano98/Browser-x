# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub's
[private vulnerability reporting](https://github.com/condoriano98/Browser-x/security/advisories/new).
Do not open public issues for security problems.

- We acknowledge reports within 3 business days.
- We aim to fix and disclose within 90 days, sooner for actively exploited issues.
- Vulnerabilities in upstream Chromium are reported to the Chromium project
  (https://www.chromium.org/Home/chromium-security/reporting-security-bugs/).

## Supported versions

Only the latest release is supported. Browser-x follows Chromium stable. Builds more than one
Chromium milestone behind are unsupported, and IT can enforce a minimum version by policy.

## Security update targets

| Upstream Chromium release | Browser-x release target |
|---|---|
| Fixes a vulnerability exploited in the wild | within 72 hours |
| Other security fixes | within 7 days |
| New milestone | within 14 days |
